# Food Delivery Data Analysis

## Overview
This project presents an **end-to-end data analysis** of a food delivery platform dataset aimed at uncovering actionable business insights.  
The analysis focuses on customer behavior, order trends, city-wise revenue distribution, and restaurant performance.

Developed as part of a **technical hackathon**, the project demonstrates practical skills in data wrangling, exploratory data analysis, SQL querying, and data visualization.

---

## Objectives
- Clean and preprocess raw data from multiple sources  
- Perform exploratory data analysis (EDA) to identify patterns and trends  
- Analyze revenue and order distribution across cities and restaurants  
- Understand customer ordering behavior  
- Generate visual insights to support data-driven decision-making  

---

## Technology Stack
- **Programming Language:** Python  
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn  
- **Database & Querying:** SQLite (SQL)  
- **Tools:** Jupyter Notebook  

---

## Dataset Description
The project uses multiple data sources:
- `orders.csv` – Order-level transactional data  
- `users.json` – Customer-related information  
- `restaurants.sql` – Restaurant data and SQL queries  
- `final_food_delivery_dataset.csv` – Cleaned and merged dataset used for analysis  

---

## Methodology
1. **Data Cleaning & Preprocessing**  
   - Handling missing values  
   - Data type standardization  
   - Merging datasets from multiple sources  

2. **Exploratory Data Analysis (EDA)**  
   - Descriptive statistical analysis  
   - Trend and distribution evaluation  

3. **SQL Analysis**  
   - Querying structured data using SQLite  
   - Aggregation and filtering for insights  

4. **Data Visualization**  
   - Revenue and order trend analysis  
   - City-wise and restaurant-wise performance comparison

## Key Insights
- Identified high-revenue cities and top-performing restaurants  
- Evaluated customer ordering frequency and behavior patterns
