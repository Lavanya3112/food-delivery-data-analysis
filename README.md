# 🍔 Food Delivery Data Analysis

## 📌 Overview
The Food Delivery Data Analysis project focuses on performing an **end-to-end analysis** of a food delivery platform dataset to uncover meaningful business insights.

This project was developed as part of a **technical hackathon** and showcases practical skills in data analysis, SQL querying, and data visualization.

---

## 🛠 Technologies Used
- Python  
- Pandas  
- NumPy  
- Matplotlib  
- Seaborn  
- SQLite (SQL)  
- Jupyter Notebook  

---

## ✨ Key Features
- Data cleaning and preprocessing  
- Exploratory Data Analysis (EDA)  
- SQL-based querying using SQLite  
- City-wise and restaurant-wise analysis  
- Revenue and order trend visualization  
- Business insight generation  

---

## 📂 Dataset Used
- Orders data (`orders.csv`)  
- User data (`users.json`)  
- Restaurant data & SQL queries (`restaurants.sql`)  
- Final cleaned dataset (`final_food_delivery_dataset.csv`)  

---

## 🚀 How to Run the Project
1. Clone the repository  
2. Open `FD_Analysis.ipynb` in Jupyter Notebook  
3. Install required Python libraries  
4. Run the notebook cells sequentially
